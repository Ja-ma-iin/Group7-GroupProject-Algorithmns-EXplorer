ALGORITHM EXPLORER

Group: Group 7
Programming Language: Java

1. Introduction

Algorithm Explorer is a Java desktop application that demonstrates how different algorithms and data structures work.

The application allows users to enter their own inputs, execute algorithms and view the results, operations performed and execution time.

The project covers four main areas: recursion, data structures, sorting algorithms and time complexity analysis.

2. Project Objectives

Demonstrate how recursive algorithms work.

Implement fundamental data structures from first principles.

Implement and compare different sorting algorithms.

Measure algorithm performance using execution time and operation counts.

Provide an interactive graphical interface for learning algorithms.

3. Main Features

A. Recursion Lab

Fibonacci using naive recursion, memoization and dynamic programming.

Factorial using recursive and iterative methods.

Tower of Hanoi with animated disk movements.

B. Data Structures Lab

Array-based stack.

Linear queue.

Circular queue.

Singly linked list.

Doubly linked list.

Bracket balancing using a stack.

C. Sorting Lab

The application covers five sorting algorithms:

Bubble Sort

Selection Sort

Insertion Sort

Merge Sort

Quick Sort

Users can provide their own numbers or generate random data, execute sorting algorithms and examine their performance.

D. Time Complexity Analysis

This module examines sorting algorithm performance using different input sizes and input conditions.

The analysis considers:

Random input.

Already sorted input.

Reverse-sorted input.

Execution time.

Comparisons and swaps or moves.

Performance comparisons between algorithms.

4. Technologies Used

Java: Main programming language.

Java Swing: Graphical user interface.

GitHub: Collaborative development and source code hosting.

Overleaf: Preparation of the project report.

5. Project Structure

The project source code is organised into separate packages:

algorithms: Contains recursion algorithm implementations.

datastructures: Contains stack, queue and linked list implementations.

sorting: Contains sorting algorithm implementations.

frontend: Contains application windows, panels and graphical components.

backend: Contains testing classes and supporting backend functionality.

utils: Contains supporting utility classes and performance metrics.

6. Installation and Execution

Requirements

Before running the application, ensure that you have:

Java Development Kit (JDK) installed.

A Java-compatible IDE such as Visual Studio Code, IntelliJ IDEA or Eclipse.

Git installed if you want to clone the repository.

Dependencies

The application uses Java Swing and standard Java libraries.

No additional external libraries or dependencies are required.

7. Running the Application Using Visual Studio Code

Install the Java Extension Pack in Visual Studio Code.

Open the Algorithm Explorer project folder.

Navigate to:

src/main/java/frontend/Main.java

Open the Main.java file.

Click Run above the main() method.

The Algorithm Explorer graphical application will launch.
